# Mermaid Graphs
A collection of graphs of all kind, made by me, Andreas Langenhagen.

## Rendering

Mermaid renders nicely by many Markdown viewers, e.g. VSCode and when viewing a Markdown file on
Github/Gitlab.  
You can also produce standalone outputs, e.g. via `merman-cli`:

```bash
merman-cli -i in.mmd -o out.svg
merman-cli --scale 3 -i in.mmd -o out.png
```
